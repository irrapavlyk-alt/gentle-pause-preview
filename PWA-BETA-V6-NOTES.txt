Therefore screen.height - innerHeight == safe-area-inset-top.

V6 RULE
- No device model, screen size, or 48px correction is hard-coded.
- Only on iOS Home Screen (navigator.standalone === true), runtime measures:
  1) screen.height - innerHeight
  2) env(safe-area-inset-top)
- If those two measured values match within 2px, WebKit has already excluded
  the top safe-area from the standalone viewport.
- Only then the frame stops reserving that top inset a second time and uses
  the original 6px design padding.
- Bottom safe-area remains fully protected with env(safe-area-inset-bottom).
- Android does not receive the iOS correction.
- Safari/browser does not receive the correction.
- Existing Grid remains: card minmax(0,1fr), controls 50px, gap 8px.
