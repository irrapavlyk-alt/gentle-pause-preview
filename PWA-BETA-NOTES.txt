V5 CHANGES — STANDALONE MOBILE ONLY
1. Detect installed-app mode using display-mode: standalone with
   navigator.standalone fallback for iOS.
2. Read the live Visual Viewport height when available; fall back to innerHeight.
3. Store that measured height in --pwa-vh.
4. Use the measured height only for .stage/.screen in installed mobile PWA mode.
5. Keep the existing CSS Grid model:
   card minmax(0,1fr) + 50px button + 8px gap.
6. Keep device-provided safe areas via env(safe-area-inset-top/right/bottom/left).
7. Recalculate on viewport resize, orientation change, VisualViewport changes,
   and when the PWA returns to the foreground.
8. Optional diagnostic mode: append ?layoutdebug=1 to show measured viewport,
   frame/card/button heights and computed frame padding. It is invisible otherwise.
